# Psoriasis Detection Tool

This project is a machine learning-based psoriasis detection tool built with **Flask** for the backend and **TensorFlow** for the model. The tool uses computer vision to identify psoriasis patches in images uploaded by the user and highlights them based on intensity.

## Features
- **Image Upload**: Users can upload images for psoriasis detection.
- **Prediction**: Classifies the image as **Psoriasis** or **Normal**.
- **Highlight Psoriasis**: Highlights the psoriasis patches with a color map based on intensity.

## Technologies Used
- **Flask** (Backend)
- **TensorFlow** (Model for psoriasis detection)
- **OpenCV** (For image processing and highlighting patches)
- **HTML, CSS, JavaScript** (Frontend)
